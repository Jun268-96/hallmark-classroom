# Hallmark Classroom

수업용 웹 자료의 **설명과 화면 구조를 크게 간소화하고, 학생의 조작과 결과를 크게 보여주는** 디자인 스킬입니다. 로컬 Hallmark 1.1.0의 원칙을 수업 자료용으로 재구성한 독립 버전입니다.

색·문구·아이콘만 바꾼 결과는 완료로 보지 않습니다. 정보가 많은 조작 자료에서는 비필수 설명과 독립 설명 패널을 각각 절반 이하로 줄이는 것을 기본 목표로 두고, 카드의 통합·이동과 실제 학습 대상의 확대를 확인합니다. 필수 내용과 기존 기능·정답 로직은 보존합니다. 읽기 자체가 과제인 자료와 좁은 수정 요청에는 이 기준을 일괄 적용하지 않습니다.

## 스킬로 사용하기

[SKILL.md](SKILL.md)를 포함한 이 저장소를 `hallmark-classroom` 스킬 폴더로 설치한 뒤 호출합니다.

```text
$hallmark-classroom으로 이 수업 자료를 재구성해줘.
```

우선순위: 학생의 행동 → 정보 간소화 → 배치 → 시각적 피드백 → 스타일.
색상만 바꾸는 대신 실제 정보 구조와 상호작용을 개선하도록 구성했습니다. 결과는 적용 후 실제 화면과 동작으로 확인해야 합니다.
